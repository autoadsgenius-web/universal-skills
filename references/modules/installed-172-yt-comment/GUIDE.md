# yt-comment

## Finalidade

Draft replies to YouTube comments in the creator's voice, triaged by which ones are worth answering. Use for "reply to my comments", "handle the comment section", "someone asked X", or a pasted comment thread.

## Dependência

Se não estiver, indique essa dependência sem inventar um comando de instalação ou resultado.

Na ausência dele, entregue somente as partes que puder concluir com as ferramentas atuais e explique o que ficou pendente. Verifique o resultado antes de informar sucesso.
