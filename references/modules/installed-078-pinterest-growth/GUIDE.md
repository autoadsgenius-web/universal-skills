# pinterest-growth

## Finalidade

The Pinterest growth playbook for 2026. Use when someone wants to "grow on Pinterest," "get traffic from Pinterest," "a Pinterest strategy," a pin cadence/board structure, or to turn blog/product content into pins. Pinterest is a visual SEARCH engine where keyword-optimized, fresh, vertical pins compound into evergreen outbound traffic — optimise for discoverability + clicks, not in-the-moment engagement. Uses the PINS framework. Reads brand-profile + voice-builder first. The agent drafts pins + the schedule; WoopSocial schedules/publishes pins; metrics come from native Pinterest Analytics; nothing is fabricated. For "Pinterest SEO" / "rank my pins" / keyword titles-descriptions route to pinterest-seo; for designing the pin image route to pinterest-pin-design. Pairs with content-recycling.
