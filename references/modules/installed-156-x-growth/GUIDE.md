# x-growth

## Finalidade

The X/Twitter growth playbook for 2026. Use when someone wants to "grow on X / Twitter," "get more reach/followers/impressions on X," "an X content/posting strategy," "should I get X Premium," "how the X algorithm works," or how to use replies/quote-posts/long-form/video to grow. Conversation is the engine (replies and first-hour velocity), Premium is effectively a baseline, and links go in the first reply. Uses the SPARK framework. Reads brand-profile + voice-builder first. The agent drafts posts + reply copy; a human does the live replying/quote-posts/community engagement; WoopSocial schedules posts; metrics come from native X analytics; nothing is fabricated. Complements thread-writer (thread-format craft).
