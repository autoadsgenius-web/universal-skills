# youtube-seo-optimize

## Finalidade

Advanced YouTube metadata optimizer. Generates Browse-primary and Search-primary title variants, entity-rich descriptions, tags, chapters with Key Moments schema, 15-second hook script, translated metadata for top markets, pinned comment, and end-screen plan. Use when user says "optimize my video", "rewrite my title", "write YouTube description", "generate tags", or provides raw video info asking for metadata.
